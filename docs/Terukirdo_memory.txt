events and `MEMORY.md` for the repository-facing summary.

Stable Learnings
----------------
- Preserve user changes in a dirty worktree and avoid unrelated refactors.
- Run build and test verification before committing repository-wide changes.
- Keep generated artifacts, local credentials, and test results out of Git.
- Review secret-pattern matches in context because security tests may contain
  intentional fixture values.
- Several legacy C# files have mixed or invalid encoding. Apply comment or
  documentation rewrites in small, encoding-safe scopes and verify the build.
