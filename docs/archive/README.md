# Archive Directory

> [!WARNING]
> **DO NOT USE AS CONTEXT / 메인 컨텍스트 포함 금지**

이 디렉토리는 과거의 규정, 프로토콜, 구조체 등을 보존하기 위해 존재하는 기록 보관소입니다.
테르키르도(에이전트)를 비롯한 어떠한 LLM도 현재 워크스페이스의 작동 규칙이나 SSOT(Single Source of Truth)를 파악할 목적으로 이 폴더의 문서를 참조하거나 메인 컨텍스트에 포함해서는 안 됩니다.

이곳에 있는 문서들은 더 이상 유효하지 않은 폐기된 규칙이므로, 오직 "과거에는 이랬다"는 역사적 기록 및 성장의 증거로서만 열람해야 합니다.
