## Scope Rules

- Add only behavior needed for the target user outcome.
- Report unclear or unresolved scope items first; move them to `docs/handoff/open-questions.md` only after user request or approval.
- Treat auth, payment, privacy, data deletion, and deployment scope as high-risk.
