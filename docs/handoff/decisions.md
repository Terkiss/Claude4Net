## Rules

- 사용자 발화나 합의로 확정된 결정만 기록한다.
- 추정이나 질문은 이 문서에 쓰지 않는다.
- 순수 제안은 `docs/handoff/next-actions.md` 또는 `docs/handoff/open-questions.md`에 둔다.
- `active`: 다음 작업에서 바로 참고해야 하는 확정 결정.
- `pending-domain-insert`: domain docs로 옮길 후보지만 아직 이동 승인이 없는 확정 결정.
- `approved-to-move`: 사용자가 domain docs 반영을 승인한 확정 결정.
- `moved` 또는 `superseded`: 오래 남기지 않고 정리 대상이다.
- Domain docs로 옮길 후보는 `Target doc`, `Insert section`, `Content`를 포함한다.
- Domain docs로 옮긴 뒤에는 항목을 제거하거나 필요한 경우 짧은 링크만 남긴다.
- High-risk 결정은 작아 보여도 갱신 필요성을 보고하고 사용자 요청 또는 승인 후 기록한다.
