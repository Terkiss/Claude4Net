[1. 작업 개요]
--------------------------------------------------------------------------------
Claude4Net의 in-process OpenAI-호환 API 서버(Kestrel, 기본 포트 7836)의
호환성·격리·보안을 완성하는 작업. 대상 엔드포인트:
  GET  /v1/models, /v1/models/{id}
  POST /v1/chat/completions (SSE 스트리밍 + 논스트리밍)
  POST /v1/completions (legacy)
  POST /v1/embeddings
  /api/v1/* (health/status/usage/tools/skills; agent/run은 영구 비활성 403)
제외 범위: POST /v1/responses (구현 안 함, README에 NOT IMPLEMENTED 명시).

Baseline(커밋 3f042a4)에서 시작해 dirty worktree를 보존하며 진행.
원본 13개 blocker(S1-S4,T1-T2,R1-R2,U1,D1,C1,I1-I2)를 Wave 1-10으로 수정,
