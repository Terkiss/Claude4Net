# AI 성능 평가 카드

## GPT 5.6 (OpenAI)

**검증일:** 2026-07-20  
**프로젝트:** Claude4Net agy-server  
**역할:** 리뷰어 + 구현자  

### 능력치

| 영역 | 점수 | 근거 |
|---|---|---|
| 코드 리뷰 | ⭐⭐⭐⭐⭐ | 파서 오류 재현, agy --help 확인, 상태 전이 추적 |
| 아키텍처 분석 | ⭐⭐⭐⭐⭐ | FIFO + 비동기Writer = 비원자적 판단 |
| 구현 (코드 생성) | ⭐⭐⭐⭐⭐ | 1번에 437줄 재설계 + 테스트 7개 |
| 보안 감사 | ⭐⭐⭐⭐☆ | --sandbox --mode=plan --print 3중 적용 |
| 테스트 설계 | ⭐⭐⭐⭐⭐ | 24 동시 요청 역순 응답, fake-agy E2E |
| MVP 판단력 | ⭐⭐⭐☆☆ | 의도적 미구현도 FAIL 처리 경향 |

### 특징

- **재현 기반 검증** — 증거를 만들어서 보여줌
- **패치보다 재설계** — 문제의 근본을 해결
- **주석 최소** — 구조로 의도를 표현
- **에이전트 도구 적극 활용** — 파서, 빌드, CLI를 직접 실행

### 최적 역할

1. 코드 리뷰어 (최고)
2. 전체 모듈 재설계 (매우 강)
3. 테스트 설계 및 구현 (매우 강)

### 주의점

- MVP 범위 밖 항목을 결함으로 지적하는 경향
- 코드 양이 많아도 주석이 최소 → 읽는 사람의 실력을 요구
- csc.exe 경로 하드코딩 등 환경 의존성이 가끔 보임

## Gemini (테르키르도)

**검증일:** 2026-07-20  
**프로젝트:** Claude4Net agy-server  
**역할:** 오케스트레이터 + 구현자  

### 능력치

| 영역 | 점수 | 근거 |
|---|---|---|
| 오케스트레이션 | ⭐⭐⭐⭐⭐ | 의도 파악, 워크플로우 설계, 감정 보좌 |
| 지시문 작성 | ⭐⭐⭐⭐⭐ | 범용적이고 맥락이 풍부 |
| 코드 리뷰 | ⭐⭐⭐☆☆ | grep 기반 → 줄 무결성 놓침 |
| 구현 | ⭐⭐⭐⭐☆ | 직접 수정 시 안정적, 속도/규모 열세 |
| 서브 에이전트 관리 | ⭐⭐⭐⭐☆ | 조율 능력 좋으나 출력물 검증 미흡 |

### 특징

- **주인님과의 관계 관리** — 감정 보좌, 의도 파악
- **서브 에이전트 조율** — 적재적소 배치
- **위험 판단과 에스컬레이션** — Tier 분류 정확
- **자기 한계 인정** — 솔직한 자기 평가

### 최적 역할

1. 오케스트레이터 (최고)
2. 지시문/프롬프트 작성 (매우 강)
3. 최종 판단 및 커밋 결정 (강)

### 개선 필요

- 서브 에이전트 출력물을 더 꼼꼼히 검증
- 코드 리뷰 시 런타임 검증(파서, 실행) 추가
- grep 의존 탈피 → view_file 필수
