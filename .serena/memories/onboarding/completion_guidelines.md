# Post-Task Completion Guidelines

When a task is completed:
1. **Build:** Ensure the project builds successfully using `dotnet build`.
2. **Test:** Run relevant tests using `dotnet test` to ensure no regressions.
3. **Format/Lint:** Follow existing code style. (Currently, no specific automated linting tool is explicitly mentioned beyond standard compiler checks).
4. **Documentation:** Update `README.md` or other relevant documentation if necessary.
5. **Verify:** Manually verify the change if applicable by running the application.
