# Suggested Commands

### Development
- **Build the solution:** `dotnet build`
- **Run the CLI application:** `dotnet run --project Claude4Net.Cli`
- **Clean the solution:** `dotnet clean`

### Testing
- **Run all tests:** `dotnet test`
- **Run specific test project:** `dotnet test Claude4Net.Tests/Claude4Net.Tests.csproj`

### System Utilities (Windows)
- **List directory:** `ls` or `dir`
- **Search in files:** `grep` (if available via tools like ripgrep or git bash) or `findstr`
- **Git operations:** `git status`, `git add`, `git commit`, `git diff`
